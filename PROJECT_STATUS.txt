1. สรุปภาพรวมและสถาปัตยกรรมระบบ (Architecture Summary)
================================================================================
- Frontend: Astro 5 + Svelte 5 (Vanilla CSS ธีม Obsidian OLED & Crimson Ember)
- Native Shell: Tauri v2 + Rust + ExoPlayer Android Shell
- Cloud Database: Supabase (PostgreSQL + PostgREST API)
- ระบบความปลอดภัย: AES-256-GCM Zero-Knowledge Encryption (เข้ารหัสข้อมูลลิงก์ก่อนส่งขึ้น Cloud)
- CI/CD Build: GitHub Actions Cloud Build ประกอบไฟล์ APK ฟรีอัตโนมัติบน Cloud
- ค่าใช้จ่ายเซิร์ฟเวอร์: 0 บาท (ไม่ต้องเปิดคอม ไม่ต้องเช่า VPS)

5. วิธีการกลับมาเปิดหรือพัฒนาต่อในอนาคต (How to Resume)
================================================================================
1. เปิดเซิร์ฟเวอร์รันในคอมพิวเตอร์:
   cd "d:\IPTV & Streaming App"
   pnpm run dev
   (เข้าดูที่ http://localhost:4321 หรือหลังบ้าน http://localhost:4321/admin/)

2. เมื่อมีการแก้โค้ดและต้องการสร้างไฟล์ APK ใหม่:
   & "D:\Android\MinGit\cmd\git.exe" add .
   & "D:\Android\MinGit\cmd\git.exe" commit -m "feat: ข้อความอธิบายการแก้"
   & "D:\Android\MinGit\cmd\git.exe" push origin main
   (GitHub Actions จะสร้าง APK ให้เองบนคลาวด์ใน 8-10 นาที)

3. ดึงไฟล์ APK ตัวใหม่ลงคอมพิวเตอร์:
   $env:PATH = "D:\Android\MinGit\cmd;D:\Android\bin;" + $env:PATH
   gh release download --repo maisternco551-blip/extreme-infinitv-custom --dir "D:\IPTV & Streaming App" --clobber
